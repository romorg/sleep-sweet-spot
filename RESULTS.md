# Results and interpretation: Stage 1

Data cutoff: October 1, 2026. Observational single-participant evidence, without standardized historical daytime outcomes.

## Audit ledger

| Analysis | Observations | Result | Evidentiary boundary |
| --- | ---: | --- | --- |
| Source inventory | 60,903 sleep intervals | Multiple sources and categories across 2016–2026 | Source-record count is not nights or physiological duration |
| Reconstructed Watch windows | 2,139 | Local noon-to-noon containers | Not necessarily uninterrupted sleep |
| Eligible timing windows | 2,058 | Main Watch timing cohort | 2020–2026, quality-filtered |
| Consecutive windows | 1,933 pairs | Exact next-calendar-day linkage | Some travel/source changes |
| Complete three-window sequences | 1,817 | 219 start below 5h | Regression to mean and confounding |
| Eligible stage windows | 1,381 | 105 split under 60m rule | Separate 2022–2026 cohort; no private date exclusions |

## Timing associations

| Outcome, per one hour later onset | Estimate | Exploratory 95% confidence interval |
| --- | ---: | ---: |
| Recorded sleep duration | **−29.73 min** | [−32.05, −27.42] |
| Final recorded sleep time | **+23.76 min** | [+21.38, +26.13] |

Models descriptively account for year, month and weekday; clustered uncertainty by calendar month-year. These two associations share a mathematical relationship between onset, end, and total sleep; they should not be interpreted as independent causal pathways or translated into an expected next-day outcome.

**Coverage warning:** 729 of 2,058 timing windows (35.4%) have some internal unmeasured interval. These gaps are not automatically recorded wakefulness. Excluding the single window that crosses the local-noon boundary barely changes the slope of duration (−29.732 versus −29.733 minutes per hour); that is a sensitivity check, not permission to ignore boundary cases.

## Following nights

| First recorded window | Median first | Median next | Median third | Complete sequences |
| --- | ---: | ---: | ---: | ---: |
| Under five hours | 4h 30m | 6h 51m | 6h 47m | 219 |

This shows observed next-night behavior, **not recovery of sleep debt**. The 5h cut point was selected for comparison, not identified as a sufficient duration. If a night's continuation becomes a different decision after seeing these results, whether that improves the following day still requires prospective evaluation.

## Stage-level cohort and split sensitivity

| Rule | Matching windows / 1,381 | Share |
| --- | ---: | ---: |
| Split with gap ≥60m | 105 | 7.60% |
| Split with gap ≥90m | 74 | 5.36% |
| Split with gap ≥120m | 48 | 3.48% |

Stage cohort medians: **399 minutes total sleep**, **280 minutes Core**, **69 minutes REM**, **43 minutes Deep**, and **6.5 minutes explicitly recorded Awake**. These component medians are calculated separately, so they do not necessarily sum to the median total.

An alternate private analysis excludes four specially annotated windows and has **1,377** eligible windows, with the same **105** split events. We deliberately do **not** use the private-exclusion cohort as the main public result: an independently running analyst would not know which dates to remove. The full-cohort estimate is more transparent.

## What this changes, and what it does not

The action-level result so far is a **better-framed late-night decision**: a later sleep start has historically not been offset by an equally late ending. Deciding to stay out can still be worthwhile. Stage 1 does **not** establish a personalized minimum, optimum, causal sleep effect, psychological benefit, or effect on long-term health.
